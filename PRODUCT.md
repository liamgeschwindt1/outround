## What is it
The commercial memory and coordination system for modern revenue teams. CRMs store records. Outround stores reality.

Every call resets memory. Every rep rebuilds context. Every CRM becomes fiction five minutes after the meeting ends. Outround fixes this with persistent commercial memory and the coordination layer that turns memory into action.

## Target users
- **Primary**: B2B SaaS founders and early sales reps (1–10 reps) at 10–50 person companies
- **Geography**: Netherlands first, English-first UK/Ireland/Nordic second
- **CRM**: Pipedrive or HubSpot already installed
- **RevOps maturity**: None — no dedicated ops hire yet
- **Context**: Outbound-heavy, post-call admin is the core pain

## Core workflows (V1)
1. **Pre-Meeting Intelligence Brief** — delivered in Slack 15 min before the call. Account history, stakeholder context, prior objections, deal risk flags, next-best questions. No searching required.
2. **CRM Completion Engine** — after the meeting: CRM fields populated automatically with source citations, follow-up drafted, next steps structured. Rep reviews instead of reconstructs.

## Brand personality
Precise. Purposeful. Unfussy.

- Confident without being loud
- Dense information presented with clarity
- Dark-first — reps live in dark UIs
- No gamification, no scores, no coaching metaphors

## Anti-references
- No practice/roleplay/training framing
- No gamification (scores, streaks, badges)
- No "coach" metaphors — Outround is infrastructure, not a trainer
- No cream/beige/sand warm-neutral backgrounds
- No uniform entrance animations on every section
- No generic SaaS glassmorphism

## Language rules
**Use**: brief, memory, context, coordination, capture, intelligence, CRM, follow-up, next steps, relationship, continuity, signal, digest, meeting, session  
**Never use**: practice, roleplay, train, training, drill, coach (as verb), score, grade, round (as in practice round), persona, simulation

## Design principles
1. Information density over whitespace theatre
2. Every pixel earns its place — no decorative complexity
3. The interface disappears; the intelligence stays
4. Dark by default — this is a tool used before, during and after calls

## Tech stack
React + TypeScript + Vite (app), Supabase auth, Recall.ai capture, Gladia transcription, Claude API intelligence, Slack delivery, HubSpot/Pipedrive CRM.
